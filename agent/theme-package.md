# Black-Gold Theme Package

## Intent

Turn the existing UI into a black-gold luxury shell without changing layout. The theme should feel like a complete package: colors, surfaces, buttons, image backdrops, textures, and active states all switch together.

## Assets

- Desktop wallpaper: optional photo backdrop from the manifest, used only by signature themes
- Mobile wallpaper: dedicated alternate backdrop for signature themes
- Panel texture: subtle overlay for glass surfaces
- Accent texture: high-light source for chips, headers, and buttons
- Default theme: no wallpaper, only clean gradient or subtle noise

## Constraints

- No structural layout changes.
- No new navigation tiers.
- Theme switching must remain local-storage backed and immediate.
